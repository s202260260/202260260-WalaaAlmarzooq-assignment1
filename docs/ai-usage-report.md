# AI Usage Report

## Tools Used & Use Cases

I used ChatGPT during this assignment.

ChatGPT was used to:
- Help me understand the assignment requirements.
- Explain HTML, CSS, and JavaScript concepts.
- Suggest a clear project structure.
- Help create and organize the portfolio sections.
- Assist with debugging and fixing warnings.
- Explain how to test the website using the browser console.

## Benefits & Challenges

Using ChatGPT helped me understand the development process more clearly and complete tasks step by step.

It was useful when I was unsure how to organize files, connect CSS and JavaScript, and fix browser warnings.

One challenge was that some suggestions needed to be adjusted based on my WebStorm setup. I also needed to review the code carefully to make sure I understood what each part was doing.

## Learning Outcomes

Through this assignment, I learned how to:

- Structure a web project using separate HTML, CSS, and JavaScript files.
- Create navigation links between different page sections.
- Build and style a contact form.
- Use CSS Flexbox and media queries for responsive design.
- Add JavaScript interaction to a form.
- Use browser developer tools to check for errors.
- Organize a project using GitHub and clear folders.

## Responsible Use & Modifications

I reviewed the AI-generated suggestions before using them in my project.

I modified the content to match my own portfolio information, projects, file structure, and development environment.

I also tested the website myself to make sure the HTML, CSS, JavaScript, navigation, contact form, and responsive design worked correctly.

AI was used as a learning and development support tool, not as a replacement for understanding the code.
